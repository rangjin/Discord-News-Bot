# Discord News Bot

1인 프로젝트 / 2025.03

매일 자정, 언론사 구분 없이 가장 조회수가 높았던 뉴스들을 전달해주는 디스코드 봇

## 프로젝트 개요

> 뉴스 조회수 크롤링 -> 데이터 저장 및 조회수 집계 -> 인기 뉴스 전송

해당 프로젝트는 위 과정을 분산 배치 시스템으로 구축하고 Discord 봇을 통해 조회수가 높은 뉴스들을 알림 형태로 제공하는 서비스 개발 프로젝트입니다. 

---
## 주요 기능
| 기능              | 설명                               |
|-----------------|----------------------------------|
| 뉴스 크롤링          | 실시간 뉴스 데이터 수집                    |
| Kafka 기반 메시지 전송 | Central 서버에서 Batch 서버로 뉴스 데이터 전송 |
| 분산 처리           | 다중 배치 서버 간 데이터 분산                |
| 조회수 집계          | 매일 자정, 하루 동안 가장 많이 조회된 뉴스 집계     |
| Quartz 클러스터링    | 하나의 배치 서버만 집계 작업 수행하도록 동기화       |
| Discord 알림      | Discord 채널로 조회수 상위 뉴스 전송         |

## 사용 기술
- **Spring Boot**: API 및 배치 로직
- **Spring Batch**: 뉴스 저장/조회수 집계
- **Apache Kafka**: 크롤링 결과 메시지 분산 전송
- **Quartz**: 배치 스케줄링 및 중복 방지
- **JDA (Java Discord API)**: Discord 채널 알림 전송 
- **MySQL**: 뉴스 데이터 저장소 
- **Jsoup**: 뉴스 크롤링
